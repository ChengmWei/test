# 金邊鍋貼：結帳串接 Google Sheet（Google Apps Script）

網站送出訂單後，透過 Google Apps Script（GAS）寫入你的 Google 試算表。整個流程不需要額外的伺服器，也不用付費。

```
顧客在網站結帳 ──POST──▶ GAS 網頁應用程式 ──寫入──▶ Google 試算表
                         │                        ├ 訂單（每張訂單一列，可改狀態）
                         │                        ├ 訂單明細（每個品項一列）
                         │                        ├ 商品（價格／上架，後端以此計價）
                         │                        └ 每日統計
                         └─ Email 通知店家（可選）
```

## 一、建立試算表與指令碼（約 5 分鐘）

1. 到 Google 雲端硬碟新增一個 **Google 試算表**，名稱例如「金邊鍋貼訂單」。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `程式碼.gs` 內容全部刪掉，貼上本資料夾 [`Code.gs`](Code.gs) 的全部內容，然後按 💾 儲存。
4. （建議）點左側 ⚙️ **專案設定**，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。接著回到編輯器打開 `appsscript.json`，把內容換成本資料夾的 [`appsscript.json`](appsscript.json)，時區就會是台北。
5. 在上方函式選單選 **`setup`**，按 **▶ 執行**。
   - 第一次執行會要求授權：選你的帳號，看到「Google 尚未驗證這個應用程式」時點 **進階 → 前往（不安全）→ 允許**。這是你自己的指令碼，可以放心允許。
   - 執行完成後，試算表會自動建立「訂單／訂單明細／商品／每日統計」四個工作表。

## 二、部署成網頁應用程式

1. 在 Apps Script 右上角點 **部署 → 新增部署作業**。
2. 點齒輪 ⚙️，類型選 **網頁應用程式**，然後依下表設定：

   | 欄位 | 設定 |
   |---|---|
   | 說明 | 金邊鍋貼訂單 v1 |
   | 執行身分 | **我** |
   | 誰可以存取 | **所有人** |

3. 按 **部署**，複製「網頁應用程式網址」，網址格式像這樣：
   `https://script.google.com/macros/s/AKfy..../exec`
4. 用瀏覽器打開這個網址。看到 `{"ok":true,"service":"golden-edge-orders",...}` 就表示部署成功。

## 三、把網址填進網站

打開 `index.html`，搜尋 `ORDER_API_URL`，把網址貼進引號內：

```js
const ORDER_API_URL = "https://script.google.com/macros/s/AKfy..../exec";
```

存檔並發布網站後，結帳按鈕會變成「確認送出訂單」，訂單也會真的寫進試算表。
如果網址留空，網站會維持原本的展示模式，不會送出任何資料。

> 這段網址也可以直接告訴 Claude，讓它幫你填好並合併。

## 四、日常使用

- **處理訂單**：在「訂單」工作表的「狀態」欄用下拉選單切換：新訂單 → 製作中 → 可取餐／配送中 → 已完成（或已取消）。每種狀態會自動套上不同顏色。
- **改價格或暫停供應**：直接修改「商品」工作表。後端只以這裡的價格計算金額，顧客無法從網頁竄改價格。若取消勾選「上架」，顧客結帳時會看到「暫停供應」的提示。
  - 注意：網站菜單上顯示的價格寫在 `index.html` 的 `products` 裡。改價格時兩邊要一起改。
- **試算表選單「金邊鍋貼」**（重新整理試算表後會出現在上方）：
  - ① 初始化工作表：重新補齊缺少的工作表與格式，不會刪除任何資料。
  - 更新每日統計：依訂單重新計算每日的訂單數與營收（已取消的訂單不計入營收）。
  - 建立一筆測試訂單：確認寫入流程是否正常。
  - 設定每日自動統計：每晚 23 點自動更新每日統計。
- **新訂單 Email 通知**：在 Apps Script 的 ⚙️ 專案設定 → **指令碼屬性** 新增 `NOTIFY_EMAIL`，值填收信信箱。多個信箱用逗號分隔。
- **訂單查詢 API**（給之後做「查詢訂單」頁面用）：
  `網址?action=status&id=GE-20261116-001&phone=0912345678`
  必須同時提供正確的訂單編號和手機號碼才會回傳訂單狀態。

## 五、修改程式後要重新部署

修改 `Code.gs` 後，到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。
這樣操作網址不會改變，網站不用跟著修改。（如果改用「新增部署作業」，會產生新的網址。）

## 內建防護

| 項目 | 說明 |
|---|---|
| 價格防竄改 | 金額由後端依「商品」表重新計算，前端送來的價格一律忽略 |
| 防重複下單 | 每次結帳帶一組前端訂單 ID。網路斷線後重送時，後端回傳第一次的結果，不會重複建單 |
| 防洗單 | 同一支手機 30 秒內只能下一張單；表單另有機器人誘餌欄位 |
| 資料驗證 | 手機格式、宅配地址、品項是否存在或上架、單項最多 99 份 |
| 公式注入 | 開頭為 `= + - @` 的文字會自動跳脫，避免在試算表中被當成公式執行 |
| 併發安全 | 使用 LockService 鎖定，同時有多人下單時流水號也不會重複 |

## 常見問題

- **網站顯示「無法連線到訂單系統」**：先用瀏覽器打開網頁應用程式網址，確認有出現 `ok:true`。再檢查部署設定的「誰可以存取」是否為 **所有人**。
- **改了程式但沒有生效**：需要依第五步「重新部署新版本」。
- **想看錯誤紀錄**：到 Apps Script 左側的 **執行作業** 查看。
